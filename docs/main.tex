\section{Introducción}
\IEEEPARstart{U}{n} sistema LPR (Licence Plate Recognition) reconoce el número de placa vehícular de una imagen capturada con una cámara a color, B/W o infrarroja. Su reconocimiento se consigue con la combinación de distintas técnicas \cite{du-ibrahim2013}.

\section{Implementación del sistema}
\subsection{Entorno de desarrollo}
Como entorno de desarrollo se ha optado por utilizar una Raspberry Pi modelo 4b con 4GB de memoria RAM y 220GB de almacenamiento SSD. Al dispositivo se le ha instalado el sistema operativo RaspberryPi OS Lite (64 bits) y ha sido configurado para manipularse por SSH a través de una red local. Se contempla que este equipo se encargue de procesar el sistema LPR de forma exclusiva pero reducir el consumo de recursos externos (UI, periféricos, aplicaciones en segundo plano, etc). Sin embargo, al instalar la versión base (Lite) es indispensable configurar el entorno instalando los siguientes paquetes:

\begin{enumerate}
    \item sudo apt update \&\& sudo apt full-upgrade -y; para verificar que el sistema operativo se encuentra completamente actualizado.
    \item sudo apt install -y python3-pip python3-setuptools build-essential; para disponer de las herramientas de compilación, interpretación y desarrollo en general.
\end{enumerate}
