# Mexican License Plate Image Augmentator
The **MLP-Augmentator** is a specialized image processing pipeline designed to transform synthetic license plate images into realistic training data. It bridges the gap between the "perfect" renders produced by the MLP-Generator and the noisy, distorted images captured by real-world sensors in varying environmental conditions. The pipeline applies 29 distinct transformation types, categorized into geometric distortions, environmental effects, and sensor noise, to ensure the OCR models are robust against Mexican road conditions.

## System Architecture
The ```augmentator.py``` script operates as a batch processor that traverses a class-based directory structure (where each folder is a Mexican state or plate format). For every input image, it generates multiple variations based on a configurable transformation registry.

### Transformation Registries
The system uses two primary registries to manage transformations. This decoupled architecture allows for easy extension of the pipeline.

**1. Geometric Transformations (```GEOMETRIC_TRANSFORMS```)**
These functions manipulate the spatial coordinates of the image to simulate camera mounting angles and vehicle motion.

| Function Name | Code Entity | Description|
| --- | --- | --- |
|```rotation``` |	```random_rotation```	| Rotates image up to 15° with auto-resizing to prevent cropping |
|```scale``` | ```random_scale``` | Zooms in/out (0.8x to 1.2x) while maintaining canvas size |
| ```perspective``` | ```random_perspective``` | Manipulates corner points to simulate 3D tilt |

**2. Environmental & Sensor Transforms (```AVAILABLE_TRANSFORMS```)**
This registry contains 26 additional effects that simulate lighting, weather, and hardware limitations.

| Category | Key Functions | Simulation Target|
|---|---|---|
| Lighting	| ```add_shadows```, ```change_brightness```, ```simulate_glare``` | Overpasses, night driving, sun reflection |
| Weather | ```add_rain```, ```add_fog```, ```add_snow``` | Adverse atmospheric conditions |
| Sensor | ```add_gaussian_noise```, ```add_motion_blur```, ```jpeg_compression``` | Low-quality CMOS sensors, high-speed capture |
| Quality | ```pixelate```, ```add_vignette```, ```gaussian_blur``` | Low resolution and lens artifacts |

## Execution and Configuration
### CLI Arguments
The script is executed via the command line, allowing for override of input/output paths and target dimensions:

- **--input_dir**: Path to images generated by MLP-Generator.
- **--output_dir**: Destination for augmented images.
- **--width / --height**: Target dimensions (default 140x70 for OCR).

### Output Naming Convention
To maintain traceability, augmented files follow a strict naming pattern: ```{original_name}_{transform_type}_{index}.png``` Example: ```ABC1234_ags_perspective_0.png```

## Usage
Basic Example:

```
python augmentator.py --input_dir ../MLP-Generator/dataset --output_dir ./augmented_dataset
```
**Note**: Make sure you run the script from the directory ```~/LPR-Sentinel/src/MLP-Augmentator```
